### 🐍 Snake Ladder Game

A simple Snake Ladder Game developed in **C Language** for practicing programming logic and core C concepts.

## 🚧 Project Status

**Work in Progress**

Currently implemented:

- 🎲 Dice rolling
- 👤 Player positions
- 🐍 Snake positions
- 🪜 Ladder positions
- 🚶 Player movement logic
- 🎯 Board position handling

The complete game loop and winning condition are still under development.

## 🛠️ Concepts Used

- Functions
- Arrays
- Loops
- Conditional Statements
- Global Variables
- Random Number Generation
- `rand()` and `srand()`
- `time.h`
