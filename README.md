## C_Language
A collection of multiple C language projects based on different core C programming topics. Each repository focuses on a specific concept or feature, with simple and practical examples to improve understanding of C programming.

---
### Projects

#### 1. Calculator

A menu-driven calculator for performing basic arithmetic operations.

**Concepts:**
- Variables & Data Types
- Input/Output
- Switch Case
- Loops
- Conditional Statements
- Arithmetic Operations
- Basic Error Handling

---


#### 2. Stone-Paper-Scissor Game

A console-based game where the player competes against the computer.

**Concepts:**
- Functions
- Conditional Statements
- Loops
- Character Handling
- Random Number Generation
- Score Tracking
- Input Validation

---

#### 3. WordQuest

A word guessing game where the player guesses a randomly selected word using a given hint.

**Concepts:**
- Structures
- Arrays
- Strings
- Functions
- Loops
- Conditional Statements
- Boolean Logic
- Random Number Generation
- Character Handling
