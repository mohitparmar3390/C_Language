## WordQuest 🎯

A simple word guessing game built in C.

### Features

- Random word selection
- Word hints
- Letter-by-letter guessing
- Duplicate guess detection
- 6 wrong attempts
- Win and game-over messages

### Concepts Used

- C Structures
- Arrays
- Strings
- Functions
- Loops
- Conditional Statements
- Random Numbers
- Boolean Logic

### How to Run

Compile the program:

```bash
gcc wordquest.c -o wordquest
````

Run:

```bash
./wordquest
```

### How to Play

1. A random word and hint are shown.
2. Guess one letter at a time.
3. Correct letters are revealed.
4. Wrong guesses increase the attempt count.
5. You have 6 wrong attempts.
6. Guess the complete word to win.

### Example

```text
=================================
          WORD QUEST
=================================

Hint: A popular Italian dish

Word: _ _ _ _ _

Enter a letter: z
Good guess! 'z' is in the word.

Word: _ _ z z _
```
