## 🧮 Simple C Calculator

Ye ek **basic Simple Calculator** hai jo maine **C language** me banaya hai.
Is project ka main goal hai C ke basic concepts ko practically use karna aur ek simple working calculator banana.

### 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🚫 Division by zero check
* 🔁 Multiple calculations kar sakte hain
* ❌ Exit option
* 💬 Basic **Hindi + English mix** user messages

### 🛠️ Concepts Used

Is project ko banate time maine C ke kuch basic concepts use kiye hain:

* `printf()` aur `scanf()`
* Variables
* `float` data type
* `while` loop
* `switch-case`
* `if-else`
* Arithmetic operators
* `break`
* `return`
* Basic input/output handling

### 💡 Program kaise kaam karta hai?

Program start hone par ek menu show hota hai:

```text
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit
```

User apni choice enter karta hai aur uske according operation perform hota hai.

Example:

```text
Apni choice dalo (1 se 5): 1

Pehla number dalo: 10
Dusra number dalo: 20

Answer = 30.00
```

Agar user division select karta hai aur second number `0` deta hai, to program error message show karta hai:

```text
0 se divide nahi kar sakte!
```
